# AgroTaigo — O Futuro do Campo

## Descrição
Página informativa sobre o agronegócio, com foco em agricultura,
tecnologia e sustentabilidade.

## Tema escolhido
AgroTaigo: inovação e desenvolvimento no campo.

## Objetivo
Apresentar informações sobre a importância da agricultura,
as tecnologias utilizadas no agronegócio e as práticas de
sustentabilidade no meio rural.

## Tecnologias utilizadas
- HTML5
- CSS3
- Flexbox
- Media Queries
- Git e GitHub
- GitHub Pages

## Recursos implementados
- Estrutura semântica HTML5.
- Menu de navegação com efeitos hover.
- Imagens com texto alternativo.
- Listas ordenadas e não ordenadas.
- Citação em bloco.
- Layout responsivo.
- Seções de conteúdo e barra informativa.

## Como executar
Abra o arquivo index.html em um navegador.
